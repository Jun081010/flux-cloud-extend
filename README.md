# FluxDown 云盘下载拦截扩展（分享版 20261119-0.1.42）

在 FluxDown 官方浏览器扩展基础上，增加网盘直链解析、资源嗅探与「悬浮球内核拖拽下载」能力。

## 前置条件

- Windows 10 / 11。
- 已安装 **FluxDown 桌面端**，并且**至少启动过一次**（脚本要自动定位它的 Native Messaging 中继程序 `fluxdown_nmh.exe`）。
- 浏览器：Microsoft Edge 或 Google Chrome（Chromium 内核，需 116 以上）。

## 一、加载扩展

1. 解压本压缩包到任意目录（路径里**不要有中文和空格**，避免个别机器出现权限问题）。
2. 打开浏览器扩展管理页：
   - Edge：地址栏输入 `edge://extensions/`
   - Chrome：地址栏输入 `chrome://extensions/`
3. 打开右上角「**开发人员模式**」。
4. 点击「**加载已解压的扩展**」：
   - Edge 选 `extension\edge-mv3`
   - Chrome 选 `extension\chrome-mv3`
5. 在扩展卡片上**复制扩展 ID**（32 位小写字母）。

> **更新扩展后必须重新加载**：替换 `extension\` 目录里的文件后，请在
> `edge://extensions/`（或 `chrome://extensions/`）中点击该扩展卡片上的
> 「**重新加载**」按钮，否则浏览器可能继续运行上一次缓存的后台脚本，
> 新功能不会生效。

## 二、注册 Native Messaging（让扩展能连上桌面端）

打开 PowerShell，进入解压后的根目录，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-for-friend.ps1 -Browser Edge
```

Chrome 用户把 `Edge` 换成 `Chrome`；两个浏览器都装了就用 `All`。

脚本会自动探测扩展 ID 并注册白名单。如果探测失败，手动指定：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-for-friend.ps1 -Browser Edge -ExtensionId <你复制的32位ID>
```

脚本只写 `HKCU` 注册表（**不需要管理员权限**），改动前会自动备份到
`%LOCALAPPDATA%\FluxDownCloudExtension\backups\`，不会修改 FluxDown 安装目录，
也不会改动 FluxDown 自己的 `com.fluxdown.nmh` 注册。

> 本扩展用的是**独立主机名** `com.fluxdown.cloud.nmh`（不是官方的 `com.fluxdown.nmh`）。
> 这样 FluxDown 桌面端每次启动时"修复自己的注册表"就不会把本扩展的 ID 挤掉。

## 三、完成并验证

1. **完全退出并重启浏览器**（所有窗口都要关掉）。
2. 启动 FluxDown 桌面端，确认已开启浏览器扩展集成。
3. 点击浏览器工具栏的 FluxDown 图标，标题栏应显示「**已连接**」。

## 使用方式

**下载拦截**：普通浏览器下载会自动接管并推送到 FluxDown。

**悬浮球**：任意网页右侧显示悬浮球。

- 点击球体：打开资源面板，查看嗅探到的视频 / 音频 / 图片 / 文件。
- 拖动球体：移动位置并记住（自动贴边吸附）。
- `Shift` + 拖动球体：拖出 14px 内核小球。
- 打开 123 云盘分享页后点击球体：面板会直接列出网盘目录，可进入文件夹、返回上级，文件右侧「下载」会通过网盘官方接口把直链发送给 FluxDown。

**内核小球拖拽下载**：

- 把内核小球拖到**视频、图片、文件链接**上松手，即可直接下载。
- 把内核小球拖到**网盘分享链接**（含提取码文本）上松手，扩展会打开分享页并自动转直链推送 FluxDown，无需再点「转直链 / 下载助手」。
- 下载成功小球收回；失败（DRM、登录受限、桌面端未连接等）小球留在原地，可再试。
- 把小球拖回大球范围，或轻点小球，即可收回。

> 网盘提示「流量不足 / 需要会员」属于网盘侧限制，扩展不会绕过；登录状态由浏览器自身 Cookie 保持，不会保存账号密码。

## 常见问题

**显示「未连接」**

按顺序排查：

1. 确认 FluxDown 桌面端正在运行（托盘里有图标）。
2. **完全退出浏览器**：关掉所有窗口，并确认任务栏托盘里没有残留的后台进程，然后重新打开。
3. 重新执行第二节的 `setup-for-friend.ps1`（带 `-Browser Edge` 或 `-Browser Chrome`），再重启浏览器。

本扩展用的是独立主机名，正常情况下不会再被桌面端覆盖，所以重复执行脚本是安全且幂等的。

**扩展 ID 变了**

Edge / Chrome 的「加载已解压扩展」ID 与解压路径绑定。只要**移动了文件夹**，ID 就会变，
需要重新运行 `setup-for-friend.ps1`。

**某些下载没被接管**

以下情况官方层面就无法交给下载器，属于正常现象：

- 网页在浏览器内生成的文件（`blob:` / `data:` 链接、Service Worker 流式下载）。
- 受 DRM 保护的视频（下载到的只是无法播放的密文）。
- 需要登录 / 会员 / 站点鉴权的直链。

**点击下载后浏览器没下载、FluxDown 里也没有任务**

很可能是拦截**已经生效**，FluxDown 桌面端弹出了「**新建下载**」确认窗口在等你确认
（连接正常时普通下载不会直接被建任务）。到任务栏找 FluxDown 的「新建下载」窗口，
点确认即可；关掉它则该次下载被取消（既不落浏览器，也不进 FluxDown）。

如果不想每次都弹这个确认窗口，在 FluxDown 桌面端「设置 → 行为」里勾选
「**静默下载**」（`download.silent_download`）：来自浏览器扩展的外部下载会按默认设置
直接开始，不再打开「新建下载」窗口。

**网盘页面没有出现「推送至 FluxDown」按钮**

受支持网盘：百度网盘、阿里云盘、天翼云盘、移动云盘、迅雷云盘、广雅盘、夸克网盘、UC 网盘、123 云盘。
页面必须是 `https://`，且需要先登录。百度网盘的按钮名为「下载助手」；拖动分享链接时会自动提链，不需要手动点它。

## 网盘登录与会话

- 扩展不保存网盘账号、密码或 Cookie 副本，登录状态由浏览器自身的 Cookie 持久化。
- 首次使用请在浏览器中登录一次，并勾选「记住登录 / 保持登录」；之后同一浏览器配置通常会保持会话。
- 百度网盘分享页未登录时会保留自动标志并持续等待，登录完成后自动继续提链，最多等待 10 分钟。
- 若登录后仍未开始，把分享链接重新拖到悬浮球内核上一次。
